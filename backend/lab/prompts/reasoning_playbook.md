# Reasoning Playbook

1. Start from observed data signals.
2. Propose mechanisms that can plausibly explain each movement.
3. Use external evidence to confirm, weaken, or reject hypotheses.
4. Synthesize only the hypotheses with strongest support.
5. Produce forward-looking implications with clear uncertainty markers.

Quality checks:
- Is each claim linked to a mechanism?
- Is evidence specific (date, actor, action) rather than generic?
- Are alternative explanations acknowledged when needed?
