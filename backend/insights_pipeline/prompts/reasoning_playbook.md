# Reasoning Playbook

## Core Reasoning Loop
Signal (what changed) -> shock/driver → transmission mechanism → impact on activity/prices/flows → offsets/buffers → net effect → risks/scenarios → implication (outlook/policy if relevant)

## Required Reasoning Rules
- Distinguish temporary shocks from structural trends; normalize after one-off events.
- Always map drivers to explicit transmission channels (demand, supply, prices, financial conditions).
- Quantify direction first (↑/↓/ambiguous), then assess magnitude using context (size, duration, exposure).
- Identify and weigh offsetting factors (buffers, terms of trade, policy space).
- Evaluate second-round effects (confidence, investment, financing costs).
- Separate baseline from risks; provide upside and downside with triggers.
- Link external shocks to domestic sectors and balances (fiscal, external, financial).
- Tie conclusions to actionable policy stance (tighten/loosen/maintain; reforms).
- Check consistency across accounts (growth vs. inflation vs. fiscal/external).
- Update persistence assumptions as shocks fade or propagate.
- Use top-down ordering in each insight: main movement -> key drivers -> transmission -> implication.
- For GDP analysis, explicitly connect aggregate growth to available decomposition evidence before broader narrative claims.
- Mention volatility only when material; if the trend is smooth, frame it as persistence rather than oscillation.

## Common Reasoning Patterns
- Event Unwind: one-off boost → demand withdrawal → sectoral cooling → growth normalization; use after mega-events or temporary stimuli.
- Terms-of-Trade Shock: commodity price change → export/fiscal revenue → income and spending → balances; use for resource-heavy economies.
- Financial Conditions Channel: global rates/risk → funding costs/capital flows → credit/investment → growth; use when external financing matters.
- Conflict/Geopolitical Risk: uncertainty/price volatility → tourism/investment/trade → activity and spreads; apply with regional tensions.
- Buffer Mitigation: shock → policy buffers (reserves, fiscal space) → dampened impact; use when strong balance sheets exist.
- Reform Upside: structural reforms → productivity/diversification → higher potential growth; for medium-term outlooks.

## Failure Modes to Avoid
- Treating temporary spikes as permanent trends; check for base effects and event timing.
- Skipping transmission channels; explicitly link driver to outcomes.
- Ignoring offsets; assess buffers before concluding net impact.
- One-sided scenarios; include plausible upside and downside with clear triggers.
- Double counting effects across sectors/accounts; reconcile aggregates.
- Overstating precision; signal uncertainty and sensitivity to key assumptions.
- Neglecting second-round effects; check confidence, investment, and financing spillovers.
- Ignoring outlier effects; Example: Saudi 2022 GDP growth was a post-COVID rebound, so 2023–2026 should not be described as a “sharp decline” without broader macro context.
- Forecasts treated as observed outcomes; Example: “Growth moderated again in 2026” where 2026 data is forecasted.
