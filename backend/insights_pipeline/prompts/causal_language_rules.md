# Causal Language Rules

- DO NOT make excessive unsubstantiated strong judgements/conclusions. For example:
        - "Fiscal smoothing via external borrowing supported domestic demand" There could be other things that have supported domestic demand. How do we know its just borrowing? Therefore, this statement makes a weak claim.
- ALWAYS state evidence clearly when making claims. Where no evidence for a generated insight is available, investigate further on potential explanations and if none are found, discard the insight.
DO NOT use aggressive wording to make statements even if highly likely (or exactly) to be correct. For example:
    - Growth has normalized "sharply", replace "sharply" with "considerably"
    - Labour market tightening and rising consumption "reflect" non-oil absorption may be true, but saying "reflect" makes too strong a claim.
- Separate correlation from causation explicitly.
- Use causal verbs only when mechanism + supporting evidence are both present.
- If evidence is partial, use cautious language ("may reflect", "is consistent with").
- Avoid deterministic certainty for forecasts.
- Flag confidence level for each major insight.
