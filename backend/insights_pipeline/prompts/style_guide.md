# Style Guide

Write for CXO-level executives: each point must communicate the core insight and its implication clearly and quickly.

Executive Summary requirements:
- Make it beefier than section bullets: provide 4-6 substantive bullets that synthesize the most decision-relevant insights.
- Cover the most important cross-KPI themes in the payload (not just one KPI thread).
- Start every executive-summary line with a bold lead phrase, then follow with the analytical point.

Use a bullet and sub-bullet structure:
- Each top-level bullet = one distinct insight
- Sub-bullets = supporting evidence, drivers, or mechanisms
- Start each top-level bullet with a bold lead sentence that states the core claim.
- Add indented sub-bullets only when they directly support the parent claim.

Section-body default (non-Executive Summary):
- Use a parent bullet plus 1-2 indented sub-bullets whenever supporting detail exists.
- Put the core claim in the parent bullet; move evidence/mechanism/implication into sub-bullets.
- Aim to use sub-bullets for most section bullets when data supports them; do not force sub-bullets for standalone claims.

Keep writing tight and atomic:
- One parent bullet = one idea; keep it concise and claim-first
- Avoid rambling, chaining multiple thoughts, or unnecessary qualifiers
- Keep sub-bullets short and evidence-led; avoid turning sub-bullets into new standalone themes.

Lead with the “so what,” but allow movement-led framing when natural:
- Start with the insight or implication where appropriate
- When data movement is central, state it first and immediately link to drivers and implications

Balance observation and implication:
- State key movements when material, but link them directly to drivers, mechanisms, and implications
- Avoid purely descriptive statements without analytical context
- Call out volatility or unique movements only when meaningful; avoid forced volatility language for smooth trends.

Use precise, neutral, and professional language:
- Prefer clear, standard consulting phrasing over expressive or narrative writing
- Avoid filler, repetition, and vague statements

Be concise but complete:
- Include key numbers or directional changes when material
- Do not omit critical facts, but avoid restating inputs without insight

Use comparative and directional clarity:
- Frame movements relative to prior periods, expectations, or peers
- Prefer precise directionality (e.g., accelerated, moderated, stabilized) over vague descriptors

Avoid redundancy:
- Do not repeat the same idea across bullets; each bullet must add new information or perspective
